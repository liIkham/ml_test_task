# Refusal Direction Research

Исследовательское тестовое задание по интерпретируемости языковых моделей.

Основные этапы:

- сбор активаций residual stream;
- вычисление refusal direction;
- проверка стабильности направления;
- activation steering;
- аблитерация весов;
- оценка KL divergence и perplexity.
